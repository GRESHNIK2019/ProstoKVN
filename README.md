# ProstoKVN

**ProstoKVN** — VPN-клиент для **Windows 10/11 x64** с гибкой маршрутизацией сайтов, IP-адресов и отдельных приложений. Поддерживаются TUN, системный прокси, несколько подписок и сетевые ядра Mihomo, sing-box и Xray.

## Основные возможности

- **Маршрутизация по приложениям.** Укажите имя процесса (например, `chrome.exe`) либо выберите конкретный `.exe`. Для правила доступны маршруты «Через VPN», «Напрямую» и «Блокировать», а также отдельный VPN-сервер.
- **Правила для сайтов и IP.** Домены, IP-адреса и подсети CIDR. В версии 0.34.2 раздел «Правила» разделён на вкладки **«Сайты и IP»** и **«Приложения»**, с независимым поиском.
- **Выборочное подключение.** Режим «Только выбранные приложения» направляет через VPN Discord и явно выбранные правила, а остальной трафик по умолчанию оставляет **DIRECT**. TUN используется для маршрутизации трафика приложений, включая UDP; ручные правила имеют приоритет.
- **Другие режимы.** «Умный», «Весь интернет через VPN» и «Без VPN». Прежние пользовательские настройки сохраняются.
- **Подписки и протоколы.** Несколько ссылок, объединённый список серверов, импорт Base64/V2Ray, Mihomo/Clash, sing-box и Xray JSON; отдельные `vless://`-ссылки. Поддерживаются VLESS/REALITY и XHTTP, Trojan gRPC/TLS, Hysteria2 и другие совместимые профили. Для Remnawave поддерживаются запросы идентификатора устройства (HWID).
- **Ограничение размера подписки.** До **100 серверов на один источник** после удаления дубликатов; источники учитываются независимо.
- **Проверка задержки.** Пинг одного сервера или всего списка с отображением прогресса и отменой. Для TCP-серверов измеряется соединение с портом, для UDP-протоколов — ICMP; результат не гарантирует работоспособность VPN.
- **Обновлённый интерфейс.** Боковое меню, переработанные формы и диалоги, светлая и тёмная темы, прокрутка больших списков и поддержка масштабирования Windows.
- **Автообновления.** Проверка стабильных версий через GitHub Releases, подтверждение загрузки, проверка SHA-256 и отдельный обновлятор с резервным копированием и попыткой отката.

## Быстрый старт

1. Скачайте установщик либо распакуйте ZIP в отдельную папку и запустите `ProstoKVN.exe`.
2. Откройте **«Подписки»** и добавьте ссылку подписки или отдельный совместимый профиль.
3. На странице **«Подключение»** выберите сервер и режим работы. Для выборочной маршрутизации приложений нужен TUN и права администратора.
4. В разделе **«Правила»** задайте, какие сайты, IP или приложения должны идти через VPN, напрямую либо блокироваться.
5. Подключитесь. При необходимости используйте проверку задержки сервера.

В режиме **«Только выбранные приложения»** соединения без совпавших правил остаются прямыми; встроенное автоматическое обучение сайтов, а также специальные маршруты Telegram и OpenAI в этом режиме отключены. Если программе нужны отдельные вспомогательные процессы, для них могут потребоваться свои правила.

## Установка и обновление

Обновление уже установленного клиента: **«Настройки → Обновления приложения → Проверить обновления»**. Приложение проверяет GitHub Releases и предлагает установить новую стабильную версию. Перед распаковкой проверяется SHA-256; во время установки VPN-соединение может временно прерываться.

Настройки, маршруты и зашифрованный кэш подписок хранятся отдельно от программы в `%LOCALAPPDATA%\ProstoKVN`. Защищённые ссылки используют Windows DPAPI. При переходе со старой версии, которая не запускается без установленного .NET, может потребоваться однократная ручная установка. Установщик не переносит автоматически прежнюю портативную папку.

## Сборка из исходников

Требуются Windows 10/11 x64 и **.NET 10 SDK**.

```powershell
dotnet build .\ProstoKVN\ProstoKVN.csproj -c Release
dotnet build .\Updater\ProstoKVN.Updater.csproj -c Release
dotnet build .\SmokeTest\SmokeTest.csproj -c Release
```

Для выпуска дистрибутивов используются скрипты в каталоге [release](release/). Установщик собирается через Inno Setup 6. Бинарные сетевые ядра поставляются в пользовательском релизе и не включены в Git-репозиторий.
