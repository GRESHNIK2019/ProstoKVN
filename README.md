# ProstoKVN

VPN-клиент для Windows 10/11 x64 с правилами для приложений, сайтов, IP-адресов и подсетей. Поддерживает несколько подписок, отдельные VLESS-ссылки, TUN, системный прокси, Mihomo, sing-box и Xray.

## Что нового

- Выбор `.exe` или имени процесса и отдельный маршрут для приложения: VPN, напрямую или блокировка.
- Компактное окно 660 × 440, обновлённые светлая и тёмная темы, постоянная навигация и понятные состояния соединения.
- Импорт отдельной ссылки `vless://`, поддержка TLS/REALITY через Xray и исправление диагностических маршрутов серверов с запятыми в названии.
- Поиск и редактирование правил без дублирования, явное редактирование подписок, уведомление о необходимости переподключения и отмена загрузки.
- Встроенная среда .NET и Native AOT обновлены до исправленной версии 10.0.15.

Все изменения после публичной версии 0.30.2: [CHANGELOG 0.33.0](release/CHANGELOG-v0.33.0.md).

## Выбор приложения

Откройте «Правила → Добавить правило → Приложение → Выбрать .exe…», задайте маршрут и сохраните. Полный путь действует на конкретный файл; имя процесса, например `chrome.exe`, — на все копии с этим именем. Для всех соединений приложений нужен TUN с правами администратора.

В умном режиме остальные приложения используют существующие правила и автоматическую маршрутизацию. В режиме DIRECT исключения отключены. После обновления приложения проверьте путь к `.exe`; вспомогательным процессам могут потребоваться отдельные правила. Пути с запятыми и маски не поддерживаются.

## Установка и обновление

Для новой установки запустите установщик. Для портативной версии распакуйте ZIP в отдельную папку и запустите `ProstoKVN.exe`. Не запускайте одновременно две копии клиента.

Для обновления существующей версии: «Настройки → Обновления приложения → Проверить обновления». Перед установкой проверяется SHA-256, обновлятор создаёт резервные копии заменяемых файлов. Соединение VPN временно прерывается.

Настройки, правила и защищённые DPAPI ссылки находятся в `%LOCALAPPDATA%\ProstoKVN` отдельно от программы. Если старая версия не запускается без .NET, один раз установите новую сборку вручную. Установщик не переносит автоматически прежнюю портативную папку.

## Сборка

Нужны Windows x64 и .NET 10 SDK:

```powershell
dotnet build .\ProstoKVN\ProstoKVN.csproj -c Release
dotnet build .\SmokeTest\SmokeTest.csproj -c Release
dotnet build .\Updater\ProstoKVN.Updater.csproj -c Release
```

Сетевые ядра поставляются в бинарном релизе и не хранятся в Git. Для установщика используется Inno Setup 6. Параметр `-Version` передаётся в метаданные установщика; версия клиента должна совпадать с пакетом. Процесс выпуска описан в [release/README.md](release/README.md).
