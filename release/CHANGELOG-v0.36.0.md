# ProstoKVN 0.36.0 — мониторинг маршрутов и исключение игровых IP из TUN

В клиенте появился отдельный раздел **Мониторинг**. Теперь маршрут можно проверить по работающему соединению, а включение правила видно прямо в списке.

## Мониторинг

- Активные соединения обновляются каждые 2 секунды: процесс, TCP/UDP, домен, IP, порт, фактический маршрут и скорость в обе стороны.
- Метки **VPN**, **DIRECT**, **Блокировка** и **Неизвестно** берутся из цепочки работающего Mihomo. Выбранный режим сам по себе не выдаётся за маршрут соединения.
- Есть поиск по процессу, домену, IP и правилу, фильтры маршрутов и счётчики соединений. Условия из наборов правил показываются вместо технических имён, если их удалось сопоставить.
- Служебные соединения сетевых ядер и диагностические пробы скрыты. Если контроллер недоступен, старые строки очищаются и появляется сообщение об отсутствии свежих данных.
- Данные мониторинга остаются в памяти: журнал посещений не создаётся и сведения о соединениях не отправляются.

## Использование правил

- В режиме **Только выбранное** у каждого правила появилась галочка включения. Можно выключить сохранённое правило без удаления и открытия редактора.
- Отдельно показано, какой режим работает сейчас и какие изменения ещё требуют применения.
- Из раздела маршрутизации можно сразу перейти к живым соединениям. Пояснение у правила приложения предупреждает, что оно действует на все соединения этого приложения.

## Игровые серверы

- В редакторе точного IP с маршрутом **Напрямую** появился параметр **Исключить этот IP из TUN**.
- Это явное исключение для всех приложений: IP обходит обработку TUN и имеет приоритет над остальными правилами. Обычный DIRECT продолжает обрабатываться ядром локально.
- Изменение исключения требует переподключения кнопкой **Применить**. Клиент не выдаёт сохранённое исключение за уже применённое.
- Монитор показывает IP, исключённые из текущего TUN. Их соединения не перехватываются ядром и поэтому отсутствуют в списке потоков.
- Исключение не включается автоматически. Снижение задержки в конкретной игре зависит от причины задержки; игровой UDP и ICMP-пинг — разные измерения.

## Проверки и пакеты

Проверены чтение реального локального контроллера, классификация цепочек, поиск и фильтры, скорости, очистка устаревших данных, интерфейс в обеих темах и при минимальном окне, сохранение выбора, приоритет исключений и обычная/горячая конфигурации на отдельном Mihomo. Дополнительно проверены прежние режимы, перенос настроек, приложения, набор YouTube, группировка и трей.

Windows x64: ZIP, установщик `UNSIGNED`, SHA-256. .NET включён. Цифровая подпись издателя отсутствует. Пользовательские настройки и подписки в пакеты не включаются.
