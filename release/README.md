# ProstoKVN — GitHub Releases и обновления

Репозиторий: https://github.com/GRESHNIK2019/ProstoKVN

## Схема
- Клиент автоматически проверяет `releases/latest` при запуске и позволяет повторить проверку в **Настройки → Обновления приложения**.
- Поддерживаются только опубликованные стабильные релизы с тегом `vMAJOR.MINOR.PATCH`.
- В релизе обязателен файл `ProstoKVN-vMAJOR.MINOR.PATCH-win-x64.zip` и контрольная сумма SHA-256: поле `digest` GitHub или файл `.zip.sha256`.
- После подтверждения скачивается ZIP, SHA-256 проверяется до распаковки, дополнительно проверяются все имена файлов.
- Временный обновлятор `ProstoKVN.Updater.exe` ждёт завершения предыдущего процесса, резервирует заменяемые файлы, копирует новые и запускает обновлённый ProstoKVN.
- При неудаче копирования/запуска обновлятор попытается восстановить предыдущие файлы и перезапустить прежнюю версию.
- Пользовательские настройки и подписка находятся вне папки приложения: `%LOCALAPPDATA%\ProstoKVN` — они не включаются в ZIP и не заменяются.
- До полного скачивания и проверки старый VPN продолжает работать. При установке программа закроется и VPN временно отключится.

## Как создавать релизы
1. Установить **.NET 10 SDK**, Windows SDK (SignTool), код-подписывающий сертификат издателя.
2. Убедиться, что `ProstoKVN.csproj` содержит номер создаваемого релиза, например `0.29.1`.
3. Подписанная публикация (пример; указать путь SignTool и действующий отпечаток сертификата):
   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\release\Build-Release.ps1 -Version 0.29.1 -SignTool 'C:\Path\signtool.exe' -CertificateThumbprint 'YOUR_CERTIFICATE_THUMBPRINT'
   ```
4. Только для изолированной разработки без сертификата допускается `-AllowUnsignedDev`. **Не распространяйте эти сборки как проверенно подписанные.**
5. Проверить `Get-AuthenticodeSignature` у EXE и подпись инсталлятора.
6. Создать стабильный GitHub Release с тегом `v0.29.1` и приложить оба файла:
   - `ProstoKVN-v0.29.1-win-x64.zip`
   - `ProstoKVN-v0.29.1-win-x64.zip.sha256`
7. Новая версия, например `v0.29.1`, должна иметь **больший номер** и соответствующий архив. Тогда установленные старые версии обнаружат её при проверке.

## Автоустановщик (Inno Setup)
Файл `release/ProstoKVN.iss` готов для Inno Setup 6. Он устанавливает приложение в
`%LOCALAPPDATA%\Programs\ProstoKVN`, не изменяет сетевые службы и не отключает Defender.
Для сборки нужен отдельно установленный Inno Setup, затем подписывается
`ProstoKVN-Setup-0.29.1.exe` через SignTool с временной меткой.

**Важно:** на текущем ПК Inno Setup и SignTool пока не обнаружены; цифровая подпись настоящим издателем ещё не сделана. Даже с валидной Authenticode подписью Microsoft SmartScreen может временно предупреждать о новом малоизвестном приложении. Избегайте обфускации/упаковщиков, не отключайте UAC/Defender. Самое предсказуемое распространение без SmartScreen download warning — Microsoft Store (MSIX).

## Меры безопасности
- ZIP получен только из точного пути GitHub Releases указанного репозитория.
- Проверяется SHA-256. Он доказывает соответствие релизу, но не заменяет **цифровую подпись издателя**.
- Запрещены опасные пути ZIP, ссылки, чрезмерный размер и подмена пользовательских файлов.
- Второй экземпляр ProstoKVN блокируется.
- Обновление не запускается без подтверждения пользователя; нет автодобавления исключений Defender.
- Прямое обновление версии `0.28` не поддерживает этот механизм: сначала требуется один раз установить `0.29` вручную.
