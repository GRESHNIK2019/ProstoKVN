# ProstoKVN — релизы и автообновления

Репозиторий: https://github.com/GRESHNIK2019/ProstoKVN

## Windows x64 / выпуск v0.30.2

Начиная с v0.30.2 приложение поставляется **автономно**: .NET 10 Desktop Runtime включён в ZIP и в установщик. Обновлятор Native AOT — отдельный Windows exe, которому не нужна .NET Runtime.

### Что публиковать
- `ProstoKVN-v0.30.2-win-x64.zip` — ZIP для пользователей, включая существующие портативные установки и обновление из v0.30.1.
- `ProstoKVN-v0.30.2-win-x64.zip.sha256` — контрольная сумма обновления.
- `ProstoKVN-Setup-0.30.2-UNSIGNED.exe` — установщик для новых пользователей, без сертификата доверенного издателя.
- `ProstoKVN-Setup-0.30.2-UNSIGNED.exe.sha256` — контрольная сумма установщика.

**Не публиковать** `*-TEST-SIGNED.exe` как официальный установщик. Самоподписанная тестовая подпись не означает доверие Windows или SmartScreen. Перед публичной загрузкой предупредить о том, что официальный сертификат отсутствует. Не советовать отключать Defender или SmartScreen.

## Автообновление

Приложение при запуске и по команде «Настройки → Обновления приложения» проверяет `GET /repos/GRESHNIK2019/ProstoKVN/releases/latest`. Обрабатываются только стабильные версии с тегом `vMAJOR.MINOR.PATCH`. Пользователь подтверждает загрузку; SHA-256 проверяется до распаковки, пути в ZIP проверяются. Отдельный обновлятор ждёт выхода приложения, делает резервные копии файлов, устанавливает обновление и перезапускает клиент. При сбое предусмотрена попытка отката.

Пользовательские настройки и подписки остаются в `%LOCALAPPDATA%\ProstoKVN` и не перезаписываются релизом. Старые клиенты, которые не запускаются без установленного .NET, не могут самостоятельно запустить обновлятор: им потребуется **однократная ручная установка ZIP или EXE**.

## Сборка
- Windows 10/11 x64, .NET 10 SDK, Inno Setup 6 и Windows SDK;
- `release/Build-Release.ps1` — создаёт автономный ZIP с контрольной суммой;
- `release/Build-Installer.ps1` — собирает установщик и, при наличии доверенного Code Signing-сертификата, выполняет подпись.

Для локальной изолированной проверки разрешён `-AllowUnsignedDev`; для доверенного публичного релиза необходим корректный сертификат. Подписывать ZIP и установщик следует согласованно; SHA-256 пересчитывать после изменений файлов.

Исходники программ и файлы *.cs, *.csproj, *.xaml, *.iss, нужные PS1 и документы публикуются отдельно от бинарных дистрибутивов. Не публикуйте приватные ссылки подписок, настройки пользователей, токены, закрытые ключи и отладочные дампы.

Лицензии Mihomo, sing-box, Xray и других библиотек включаются в бинарный пакет. Подробности — в `release/CHANGELOG-v0.30.2-reliability.md`.
