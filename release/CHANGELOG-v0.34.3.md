# ProstoKVN 0.34.3 — гибкие настройки TUN и охват доменов

## Маршрутизация сайтов

- При добавлении сайта можно выбрать охват **«Весь домен и все поддомены»** или **«Только указанный адрес»**.
- Для обоих видов правил доступны VPN, DIRECT и блокировка. Например, `example.com` через VPN, но `api.example.com` — DIRECT, или наоборот.
- Для полного домена создаётся правило Mihomo `DOMAIN-SUFFIX`; для конкретного адреса — `DOMAIN`.
- Точное правило имеет приоритет перед общим правилом родительского домена, включая hot rule providers.
- Старые правила `routes.json` сохраняют прежнюю семантику охвата всех поддоменов. Точные домены хранятся с новым служебным префиксом `domain-exact:`. Формат файла и ручные исключения для IP/приложений сохранены.
- В редакторе виден охват домена; для IP-адресов, подсетей и программ он скрывается.

## Настройки TUN

В «Настройки → Подключение и маршрутизация → Дополнительные настройки TUN»:

- Выбор сетевого стека: `mixed` (по умолчанию), `system` или `gvisor`.
- Перехват DNS-запросов на порту 53 — включён по умолчанию; можно отключить для диагностики совместимости.
- Строгая маршрутизация (`strict-route`) — выключена по умолчанию; может влиять на локальную сеть.
- Параметры сохраняются в `settings.json` и применяются при переподключении. Если уже есть активная сессия, интерфейс показывает несохранённые для сессии изменения.
- Действующие режимы «Умный», «Весь интернет через VPN», «Только выбранные приложения» и «Без VPN» сохранены. TUN сам по себе **не** отправляет весь трафик в VPN — направление задаётся выбранным режимом и правилами.
