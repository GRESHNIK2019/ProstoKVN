# ProstoKVN 0.34.1 — выборочный VPN для приложений (Split Tunneling)

- Добавлен режим подключения **«Только выбранные приложения»**. Для трафика без совпавших правил используется `MATCH,DIRECT`, а не VPN.
- Discord.exe, DiscordPTB.exe и другие поддерживаемые сборки Discord направляются через VPN по имени процесса. При включённом TUN правило охватывает и UDP-трафик голосовых вызовов.
- TUN автоматически включается при выборе нового режима. Надпись переключателя уточняет, что TUN перехватывает трафик для правил, но не означает VPN для всех программ.
- Ручные правила приложений, сайтов и IP имеют приоритет, включая явное исключение DIRECT для Discord.
- В новом режиме отключены автоматическое обучение маршрутов и встроенные маршруты Telegram / OpenAI; выбранные пользователем правила сохраняются.
- Старые режимы («Умный», «Весь интернет через VPN», «Без VPN») оставлены без смены их пользовательских настроек.
- Добавлены тесты режима, обработки UDP через локальный SOCKS5-адаптер Xray, приоритетов правил и проверки конфигурации реальным Mihomo.

**Ограничение проверки:** автоматические тесты проходят, но падение задержки Discord и реальная стабильность UDP-вызова на выбранном сервере ещё не доказаны измерением голосового звонка.
