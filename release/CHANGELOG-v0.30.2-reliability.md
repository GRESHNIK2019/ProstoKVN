# ProstoKVN 0.30.2 — Reliability / Self-contained (локальная сборка)

**Статус:** подготовлено локально, НЕ опубликовано на GitHub. Релизная версия в исходниках: 0.30.2.

## Исправления
- Клиент теперь публикуется self-contained с .NET 10 Desktop Runtime: дополнительная установка .NET не нужна.
- Обновлятор переведён на Native AOT (отдельный нативный Windows x64 exe) с генерацией JSON-метаданных при сборке, без второй копии .NET.
- Системный прокси сохраняет прежние значения в файл восстановления до применения ProstoKVN. На новом запуске после сбоя восстанавливаются ТОЛЬКО ещё принадлежащие клиенту настройки.
- Запись settings.json и routes.json теперь атомарная с .bak, чтение умеет восстановиться из резервной копии.
- Параллельная загрузка до 3 подписок, затем последовательное применение результатов в порядке профилей. Старые ответы не перезаписывают изменённые ссылки.
- HTTPS-ответ подписки ограничен до 8 МБ; размер контролируется и по Content-Length, и при потоковом чтении.
- Операции подключения, переподключения, отключения и применения маршрутов синхронизированы. Завершение GUI дожидается завершения операции, чтобы ядро не активировало прокси после выхода.
- При трёх полных проваленных проверках VPN запускается восстановление с уже существующим ограниченным backoff, без немедленного рестарта после случайного HTTP-сбоя.
- Старые законченные update stage старше суток и незавершённые старше 14 дней безопасно удаляются по строгому шаблону имени (не более 10 каталогов за запуск).
- Удалён абсолютный путь к Mihomo из каталога разработчика.
- Inno Setup installer использует AppMutex и корректно обрабатывает работающий ProstoKVN при установке обновлений.

## Совместимость
- Windows 10/11 x64 (установщик требует Windows build 17763+).
- Пользователям старых ZIP-сборок 0.29–0.30.1 с работающим приложением обновление придёт через GitHub Releases после публикации. Если версия не запускается из-за отсутствия .NET, потребуется один раз установить новую автономную сборку вручную.
- Настройки: %LOCALAPPDATA%\ProstoKVN; установщик и ZIP их не перезаписывают.
- Старые портативные папки установщик автоматически не удаляет: нельзя надёжно определить их расположение.
