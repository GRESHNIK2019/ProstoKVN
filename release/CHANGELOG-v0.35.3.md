# ProstoKVN 0.35.3 — YouTube в режиме «Только выбранное»

В режиме «Только выбранное» страница YouTube могла открываться, а ролики — не воспроизводиться. Сайт, видеопотоки и API используют разные домены. Автоматически найденные правила из умного режима не включаются в выбранное, а одного `youtube.com` для видео недостаточно.

- В разделе **Маршрутизация → Сайты и IP** появилась кнопка **Включить YouTube**. Она добавляет сайт, видеосерверы, обложки и API плеера в выбранное.
- Правила видны в отсортированной группе **YouTube / Google Video**. Их можно отдельно изменить, выключить или удалить.
- Показано, сколько адресов сервиса направлено через VPN. Повторное нажатие не создаёт дубликатов.
- Ручные исключения «напрямую» и «блокировать» сохраняют приоритет. Если YouTube закреплён за отдельным сервером, новые правила используют тот же сервер.
- При активном подключении правила обновляются без перезапуска TUN. Остальные сайты и автоматически найденные правила не включаются в VPN.

После обновления выберите **Только выбранное → Сайты и IP → Включить YouTube**, затем перезагрузите вкладку с роликом. Набор включается явно: обновление само не меняет выбранные пользователем маршруты.

Проверены сохранение правил, ручные исключения, повторное включение, обычная и горячая конфигурации Mihomo, реальные HTTP-запросы к локальному тестовому SOCKS-серверу через выбранные правила, интерфейс в обеих темах и при минимальном размере окна. Воспроизведение ролика через пользовательский сервер отдельно не проверялось.

Пакеты Windows x64: портативный ZIP, установщик `UNSIGNED` и контрольные суммы SHA-256. .NET включён. Цифровая подпись издателя отсутствует.
