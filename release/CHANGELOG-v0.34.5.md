# ProstoKVN 0.34.5 — режим «Только мои правила»

## Что изменилось

- В «Подключение → Режим подключения» добавлен режим **«Только мои правила»**.
- Трафик через VPN направляется **исключительно по явно включённым ручным правилам** для сайтов, доменов, IP/подсетей и приложений; собственные правила DIRECT и REJECT сохраняют свой приоритет.
- Остальные адреса и приложения работают напрямую: базовое правило `MATCH,DIRECT`. **Никакие** встроенные правила Discord, Telegram, ChatGPT/OpenAI, Claude, обученные сайты и другие автоматические маршруты VPN в этом режиме не включаются.
- В режиме автоматически включается TUN, чтобы правила приложений охватывали их соединения, включая UDP. TUN не означает автоматическое направление всего интернета через VPN.
- В редакторе каждого правила появилась галочка **«Использовать в режиме “Только мои правила”»**. Снятие галочки исключает правило только из нового режима, но не удаляет его и не меняет другие режимы.
- Старые записи `routes.json` **не удаляются и не мигрируют принудительно**. Для обратной совместимости прежние записи с `Manual=true` считаются включёнными, а автоматически созданные `Manual=false` — отключёнными. Для старых ручных записей, происхождение которых нельзя достоверно установить, пользователь может снять галочку в редакторе.
- Новые ручные правила помечаются отдельным явным полем `MyRuleEnabled`; сохраняются также индивидуальный VPN-сервер, точные правила доменов, поддомены, исключения DIRECT и настройки приложений.
- Обновлена генерация конфигураций Mihomo как с обычными правилами, так и с hot rule providers. Исключённые записи не попадают ни в один применяемый набор правил нового режима.
- Старые режимы («Умный режим», «Весь интернет через VPN», «Без VPN», «Только выбранные приложения») сохранены. Старый режим «Только выбранные приложения» продолжает включать Discord автоматически; новый «Только мои правила» — нет.

## Как использовать

1. Откройте «Правила → Сайты и IP» или «Приложения», выберите нужную запись и установите галочку **«Использовать в режиме “Только мои правила”»**.
2. Для нового правила включите галочку и укажите VPN, DIRECT или REJECT.
3. Откройте «Подключение», выберите **«Только мои правила»** и переподключитесь для применения нового режима. Для TUN нужны права администратора.
4. Проверяйте итоговый маршрут в Mihomo; трафик сторонних программ остаётся DIRECT, если не совпало ни одно из включённых правил.

Пример: ручное правило `82.47.130.46/32 → DIRECT` имеет приоритет. Включённые правила `example.org → VPN` и `chrome.exe → VPN` работают, остальные сайты и приложения остаются DIRECT.

## Проверки

- Сборка .NET 10 Windows x64 Release: **0 ошибок, 0 предупреждений**.
- Тесты старых ручных правил, IP исключений DIRECT, точных доменов, правил для приложений, исключённых вручную записей, автообучения и встроенных маршрутов.
- Реальный Mihomo принимает обычную и hot-rule-конфигурации нового режима. Проверено сохранение в JSON и переключение UI, включая TUN.
- Прогнаны регрессионные проверки режимов TUN, Discord, редактора сайтов и приложений, маршрутизации и диагностики.

**Важно:** старые записи с флагом «Ручное» сохраняются в режиме совместимости даже если в прошлых версиях они были созданы не самим пользователем. Для полного контроля отключите их галочку в редакторе; автоматические записи в этом режиме не применяются.
