# ProstoKVN 0.33.0 — выбор приложений и обновлённый интерфейс

Все изменения Windows-клиента после последнего публичного релиза 0.30.2, включая локальные версии 0.31, 0.31.1, 0.32 и исправления импорта VLESS.

## Правила для приложений

- В разделе «Правила» появился тип «Приложение» и кнопка «Выбрать .exe…».
- Можно выбрать исполняемый файл или ввести имя процесса, например `chrome.exe`. Полный путь действует на конкретный файл, имя — на все копии с таким именем.
- Для приложения доступны «Через VPN», «Напрямую» и «Блокировать». Для VPN можно выбрать отдельный сервер.
- Приложения отображаются в своей группе и находятся поиском по имени, пути или пользовательскому названию. В списке показывается путь без служебного префикса.
- Сохраняются совместимость существующих правил сайтов, IP и подсетей и формат `routes.json`.
- При изменении адреса или приложения старая запись заменяется без дублирования.
- Поддерживаются обычная конфигурация и наборы для обновления маршрутов без перезапуска ядра. При изменении маршрута учитываются имя и путь процесса в существующих соединениях.
- Исправлено отображение текста в полях редактора и поиска в компактном окне.

## Компактный интерфейс

- Окно по умолчанию — 660 × 440 DIP, минимальный размер — 620 × 440. Главная страница помещается без прокрутки.
- Постоянные разделы: «Подключение», «Подписки», «Правила», «Настройки» и «Помощь».
- На главном экране — состояние соединения, сервер, режим, охват приложений и одна основная кнопка подключения/отключения. Во время подключения доступна отмена.
- Если серверов нет, основное действие открывает добавление подписки. Первый запуск помещается в компактном окне.
- Изменение режима или TUN показывает уведомление с действием переподключения. Текущее соединение использует снимок настроек до их применения.
- При отмене медленной загрузки подписки соединение не запускается позднее автоматически.
- Задержка, UDP, сведения о ядре, проверка сайта и журнал находятся в «Помощи»; подробности раскрываются по запросу.
- Единая строка окна с переключением темы и кнопками сворачивания, разворачивания и закрытия; поддерживаются перетаскивание и изменение размера окна.
- Обновлены светлая и графитовая темы, фиолетовый акцент, цвета состояний, поля, переключатели, меню, подсказки и видимый фокус клавиатуры.
- Добавлены собственный знак и многоразмерная иконка Windows. Длинные списки используют тонкую полосу прокрутки без стрелок.

## Подписки и VLESS

- Добавлен импорт отдельной ссылки `vless://` без необходимости создавать подписку.
- Импорт переносит UUID, адрес и порт, транспорт, TLS/REALITY, SNI, отпечаток клиента, ALPN и параметры поддерживаемого транспорта в конфигурацию Xray.
- Нативные VLESS-профили направляются через Xray и локальный SOCKS-адаптер. Служебные соединения ядра исключены из повторного попадания в собственный TUN.
- Неполные и некорректные ссылки отклоняются до подключения. VLESS-ссылки сохраняются с защитой DPAPI и поддерживаются в зашифрованном офлайн-кэше.
- Исправлена конфигурация диагностических маршрутов Mihomo для названий серверов с запятыми: используются безопасные имена групп, отображаемое название сервера сохраняется.
- Сохранены несколько подписок, объединённый список серверов и автоопределение формата. Для изменения подписки используется явная кнопка «Изменить».

## Установка и обновление

- Новая установка: `ProstoKVN-Setup-0.33.0-UNSIGNED.exe`.
- Портативный запуск и обновление из программы: `ProstoKVN-v0.33.0-win-x64.zip`.
- Для обоих файлов опубликованы контрольные суммы `.sha256`.
- .NET 10 Desktop Runtime включён в сборку. В комплекте остаются Mihomo, sing-box, Xray, их лицензии и автономный обновлятор Native AOT.
- В существующем клиенте откройте «Настройки → Обновления приложения → Проверить обновления». Настройки, правила и подписки в `%LOCALAPPDATA%\ProstoKVN` сохраняются. На время установки VPN-соединение прерывается.
- Исправлена передача версии в сборку установщика; версия приложения проверяется перед упаковкой. Установщик и ZIP имеют номер 0.33.0.

## Как выбрать приложение

1. Откройте «Правила → Добавить правило».
2. Выберите тип «Приложение» и нажмите «Выбрать .exe…» либо введите имя процесса.
3. Выберите маршрут, при необходимости сервер, и нажмите «Сохранить».
4. Для перехвата всех соединений включите TUN и подключитесь с правами администратора.

Правило по полному пути имеет приоритет над правилом по имени процесса, затем идут ручные правила IP и сайтов. Служебные маршруты ядер и локальных сетей сохраняют свой приоритет. В режиме DIRECT пользовательские исключения отключены.

В умном режиме остальные приложения используют существующие правила сайтов и автоматическую маршрутизацию. После обновления приложения путь к `.exe` может измениться: выберите новый файл или используйте имя процесса. Для вспомогательных процессов могут потребоваться отдельные правила. Пути с запятыми и маски не поддерживаются.

## Проверки и ограничения

Проверки выпуска охватывают сборку Windows WPF, сохранение и редактирование правил приложений, поиск, совместимость сайтов и IP, приоритеты маршрутов, конфигурации настоящего Mihomo, импорт VLESS с проверкой Xray, подписки, темы, состояние подключения и пакет обновления. UI-проверки используют изолированные данные; пользовательская VPN-сессия не перезапускается. Реальная маршрутизация нового правила приложения через TUN на внешнем соединении отдельно не проверялась.

Файлы **не подписаны доверенным сертификатом Authenticode**. SmartScreen может показать предупреждение о неизвестном издателе. Проверяйте SHA-256; не отключайте защиту Windows. Тестовые самоподписанные файлы не входят в релиз.

Техническая основа правил приложений: [PROCESS-PATH и PROCESS-NAME в документации Mihomo](https://wiki.metacubex.one/en/config/rules/#process-path).
